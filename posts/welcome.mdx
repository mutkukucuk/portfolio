# Building a Modern Portfolio

This website is a testament to the power of modern web technologies. I wanted to build something that was fast, accessible, and easy to maintain.

## The Stack

For this project, I chose:

- **Next.js 14**: For the app router and server components.
- **Tailwind CSS**: For rapid styling.
- **MDX**: To write content as code.

## Why MDX?

MDX allows me to use React components inside my markdown. This is super powerful for a developer blog where I might want to show interactive demos.
